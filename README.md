
Bank Account Management System

Python OOP Micro Project

Introduction

This project is a simple banking simulation developed using Python Object-Oriented Programming (OOP).

Features

- Deposit money
- Withdraw money
- Check account balance
- Input validation
- Insufficient balance checking
- Menu-driven interface

Technologies Used

- Python
- Object-Oriented Programming
- VS Code

OOP Concepts Used

- Class
- Object
- Constructor ("__init__")
- Methods
- "self" keyword

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

python python.py
